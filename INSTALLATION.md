# Installer le thème Chaud Winter

Le thème Chaud Winter est un **thème enfant** : il s'appuie sur le thème gratuit **GeneratePress**, qui doit donc être installé en premier.

> **Avant toute chose** : si le site est déjà en ligne, fais une sauvegarde (hPanel Hostinger > Sauvegardes, ou UpdraftPlus).

## 1. Installer GeneratePress (le thème de base)
1. Tableau de bord WordPress > **Apparence > Thèmes > Ajouter**.
2. Cherche **GeneratePress**, clique sur **Installer**.
3. **Ne l'active pas** : on activera directement Chaud Winter.

## 2. Installer Chaud Winter
1. Télécharge le fichier `livraison/chaud-winter.zip`.
2. **Apparence > Thèmes > Ajouter > Téléverser un thème**, choisis le zip, puis **Installer maintenant**.
3. Clique sur **Activer**.

## 3. Saisir les coordonnées
**Apparence > Personnaliser > Chaud Winter : coordonnées** : téléphone, horaires, e-mail, adresse, et la page du bouton « Être rappelé ».
Tant qu'un champ est vide, le site affiche le repère entre crochets et un rappel apparaît dans le tableau de bord.

## 4. Les menus (facultatif pour l'instant)
**Apparence > Menus** : trois emplacements existent (en-tête, pied de page produits, pied de page informations).
Si tu ne fais rien, l'en-tête affiche automatiquement les catégories de produits et le lien Contact.

## 5. Régler la boutique
Voir **`REGLAGES_BOUTIQUE.md`** : un bouton applique les réglages (pays, TVA, virement, livraison), puis quelques champs à compléter.

## 6. Importer les produits
Voir **`IMPORT_PRODUITS.md`**.

## Mettre à jour le thème
Même méthode qu'à l'étape 2 : WordPress propose de **remplacer** la version installée par celle du zip.
